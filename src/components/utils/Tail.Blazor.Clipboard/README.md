# Tail.Blazor.Clipboard

Independent NuGet package for the TailClipboard component.

## Installation

```bash
dotnet add package Tail.Blazor.Clipboard
```

## Features

- Copy to clipboard
- Success feedback
- Full theme support with CSS variables
- MAUI Blazor Hybrid compatible
